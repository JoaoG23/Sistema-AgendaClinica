# Sistema-AgendaClinica
Ainda Desenvolvimento🤰🏽! Com nosso Portal de Agendamento para Clínicas, a jornada em direção ao bem-estar se torna mais simples e conveniente do que nunca. Agende suas consultas com confiança e comece sua jornada em direção a uma saúde melhor hoje mesmo!

# Times : 7,0 Hours

# Requisitos

## Interfaces

### Agendamentos

- [x]  Sistema deve permitir o profissional criar agendamento
- [x]  Sistema deve permitir o profissional remover agendamento
- [x]  Sistema deve permitir o profissional editar agendamento
- [x]  Sistema deve permitir o profissional listar todos agendamentos
- [x]  Sistema não deve permitir marcar dois agendamentos ao mesmo tempo para o mesmo profissional
- [x]  Sistema deve permitir visualização de agendamentos através de um ***calendário***
    - [x]  Sistema deve permitir profissional efetuar alteração dos horários de agendamentos por arrasto no calendário

### Clientes

- []  Sistema deve permitir o cliente cadastrar a si proprio.
    - [] Após o cadastro sistema deve enviar e-mail para confirmação validando email.
- []  Sistema deve permitir o cliente remover a si proprio.
- []  Sistema deve permitir o cliente editar a si proprio.
- []  Sistema deve permitir o cliente somente a si proprio.
    
### Colaborador

- []  Sistema deve permitir o profissional cadastrar um novo profissional e a si proprio.
- []  Sistema deve permitir o profissional remover um profissional e a si proprio.
- []  Sistema deve permitir o profissional editar um profissional e a si proprio.
- []  Sistema deve permitir o profissional listar todos e a si proprio.
- []  Sistema deve permitir o profissional listar a si proprio.

## OBS :
- [] Sistema deve permitir efetuar atualização agendamento para horários diferentes com mesmo ID

### Bugs:
- [] Calendário com fuso errado
